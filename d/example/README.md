# Simple example
Just calculating dot product and KL distance.

## Build
```bash
dub build
```

## Run
```bash
dub run
```

It is requiring to have a shared library of `libnumkong` in the folder

## Tests
Tested on:
- [x] macOS arm (with numkong_macos_arm64_7.1.0.dylib)
- [ ] Windows x64 (with numkong_windows_x64_7.1.0.tar)
- [ ] Linux x64 (with numkong_linux_amd64_7.1.0.so)
- [ ] Linux arm (with numkong_linux_arm64_7.1.0.so)
